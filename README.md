Microsoft Sharepoint will display a message requesting sign in needlessly.

Clicking on this dialog is a waste of time. Signing in does not actually change anything. See [this forum post](https://learn.microsoft.com/en-us/answers/questions/5608691/).

This auto-clicks on the Close button of the dialog.
